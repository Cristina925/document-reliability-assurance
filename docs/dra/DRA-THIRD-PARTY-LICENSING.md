# DRA Third-Party Licensing Inventory (Publication-Oriented)

**Document identifier:** DRA-TPL-001
**Established:** DRA-PUB-007 (Documentation and Publication Licence Closure)

This is a concise, publication-oriented map of the third-party licence categories represented across DRA's corpus and evidence base. It does not duplicate the detailed per-document acquisition record (each `DRA-ACQ-0NN` report); it summarises, by category, how public redistribution should be treated for the curated public repository. See `docs/dra/DRA-LICENSING.md` for the general licensing boundary and `docs/dra/DRA-ATTRIBUTION.md` for the complete per-document breakdown of the one category where raw bytes are actually persisted (Category 1 below).

## Notes

- This table summarises *categories*; it is not a substitute for the specific per-document determination recorded in each acquisition report. Where the two ever appear to differ for a specific document, the specific `DRA-ACQ-0NN` report controls.
- "Referenced-only" documents (the large majority of the 33-document development corpus and the 100-document DRA-GEN-001 sample) are represented in the repository solely by publisher name, source URL, recorded licence basis, and a SHA-256 digest — never by the underlying document text. For these, "raw bytes in curated public repo" is always **No**, independent of how permissive the underlying licence is, because no raw bytes exist anywhere in this repository to include or exclude.
- The only category where raw third-party bytes are actually persisted anywhere in this repository is the 25-file DRA-VAL-002 set (UK OGL v3.0 and US federal public domain only) — confirmed unchanged by direct repository search during both DRA-PUB-006 and this task.
- No legal conclusion in this table extends beyond what the cited acquisition/audit records already established. Where a category is marked REVIEW_REQUIRED, that reflects the existing record's own caution, not a new restriction invented by this document.
