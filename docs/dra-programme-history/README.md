# DRA Programme History (Superseded, Pre-Consolidation)

This directory preserves an earlier snapshot of DRA programme documentation that predates the consolidation of the authoritative record into `docs/dra/` (the top-level directory one level up from this one). It is retained for historical transparency only and is **not** part of DRA's current evidentiary or scientific basis.

Two things live here:

1. **Early milestone drafts** (`DRA-001-04B-GOVERNANCE-REPORT.md`, `DRA-001-04C-INITIAL-CORPUS-REPORT.md`, `DRA-001-05A-MINIMUM-EVALUATOR-V1.md`, `DRA-001-06-BENCHMARK-EVALUATION.md`, `DRA-001-07-BENCHMARK-EVIDENCE-GENERATION.md`, and an earlier draft of the programme index) — superseded by the current records under `docs/dra/`.
2. **The abandoned DRA-VAL-001 human-reviewer validation track** (`DRA-VAL-001A` through `DRA-VAL-001F`, and the full `validation/reviewers/` recruitment/qualification procedure set under `validation/`) — a detailed protocol for recruiting and qualifying external human reviewers to validate DRA's outputs. **This track was never executed**: its own completion report records zero applicants, zero screened applicants, and zero qualified reviewers. It was superseded by the automated, contamination-blind DRA-GEN-001 and DRA-VAL-002 studies documented in `docs/dra/`. No personal data of any real individual is contained in this directory — every reviewer-facing document here is an unused template.

If any statement here appears to conflict with `docs/dra/DRA-PUBLIC-CLAIMS.md` or the manuscript, those documents control. This directory documents the programme's history, not its current claims.
